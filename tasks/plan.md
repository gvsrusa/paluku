# Implementation Plan: Paluku

## Overview
Native macOS menu-bar app (Swift 6, SwiftUI/AppKit) with Dictation,
Edit, Agent modes; local WhisperKit STT + Ollama LLM; native Mac tools; MCP
client for cloud apps; local scheduler. See SPEC.md.

## Architecture Decisions
- All logic in `Packages/PalukuCore` (SwiftPM, testable with `swift test`); `App/` is a thin UI shell generated by XcodeGen.
- Persistence = JSON files in `~/Library/Application Support/Paluku` (history, vocab, memory, reminders, settings). ponytail: personal-scale data; SQLite if history > ~50k entries. Drops GRDB dependency.
- Dependencies: WhisperKit, MCP swift-sdk only.
- LLM behind `LLM` protocol (Ollama impl + fake for tests) — two real impls (live/fake).
- Agent tool-calling uses Ollama native `tools`; confirmation enforced in the loop, not in tools.
- Paste = pasteboard + synthetic ⌘V, clipboard restored after 300 ms.
- Hotkeys = one CGEventTap on flagsChanged + keyDown (fn = `.maskSecondaryFn`, Right ⌥ = keycode 61).

## Dependency Graph
```
Settings/Store ─┬─ LLM client ─┬─ Polish ── DictationPipeline ── App (pill overlay)
                │              └─ AgentLoop ─ Tools(native, web, MCP) ── Agent UI (cards)
Audio ── Transcriber ─┘
Hotkeys ─────────────── App coordinator
Paster / SelectionReader ── Dictation + Edit
Scheduler ── Store + AgentLoop
```

## Phases
1. Foundation: scaffold package + app, Store, LLM client, Prompts, tests.
2. Dictation slice: Audio → WhisperKit → Polish → Paste; hotkeys; pill overlay.
3. Edit mode + History + Vocabulary + Settings UI + onboarding permissions.
4. Agent slice: Right ⌥ → screen/selection context → tool loop → confirm card → TTS.
5. Native tools: Finder, Calendar, Reminders, Notes, Mail, Messages, Music, Maps, Contacts, Open app/URL, web search, weather.
6. MCP hub (stdio/HTTP) + Gmail/GCal presets; scheduler (remind/scheduled actions).
7. Benchmark script, polish, docs.

Checkpoint after each phase: `swift test` green, `xcodebuild build` green.

## Risks
| Risk | Impact | Mitigation |
|---|---|---|
| WhisperKit model download size/time | Med | Default `large-v3-turbo` w/ fallback to `base` until downloaded |
| TCC permissions can't be granted headlessly | High for verification | Unit-test logic; manual QA checklist for permissioned paths |
| Ollama tool-calling flakiness | Med | Benchmark; JSON-repair fallback; low temperature |
| Google OAuth needs user credentials | Med | Presets + docs; user drops OAuth key file |

# v1.1 — Release readiness (see SPEC.md § v1.1)

## Architecture decisions
- **Distribution:** Developer ID + notarized DMG on GitHub Releases (ADR 0001). No Mac App Store: sandbox blocks core features.
- **CI/CD:** GitHub Actions; all logic in `scripts/*.sh` so workflows stay thin and runnable locally (ADR 0002).
- **Providers:** `LLM` protocol gets a 2nd real implementation `OpenAICompatibleClient`; `ModelProvider` enum in Settings picks it (ADR 0003).
- **Secrets:** Keychain via `Security.framework` (no new dependency).
- **Updates:** poll GitHub Releases API; no Sparkle (ponytail: add Sparkle when auto-install is wanted).

## Dependency graph
```
Settings.provider ─┬─ OpenAICompatibleClient ─┐
                   └─ OllamaClient(+pull) ────┴─ LLMFactory ── Coordinator ── Model picker UI
Keychain ── MCPHub env / API key
Logger ── everywhere
Version ── UpdateChecker ── menu
scripts/build|dmg|release ── GitHub Actions ci.yml / release.yml
```

## Phases & checkpoints
- **A. Models (R1–R3):** T24 OpenAI-compatible client (TDD) → T25 pull + catalog → T26 pickers UI. ✔ checkpoint: unit + live tests, app build, snapshots.
- **B. Platform (R7, R8, R10):** T27 Keychain secrets → T28 Logger + diagnostics → T29 version + update check. ✔ checkpoint.
- **C. Pipeline (R4–R6):** T30 scripts (build, dmg, release, notarize) → T31 CI + release workflows → CHANGELOG. ✔ checkpoint: scripts run locally; CI green on GitHub.
- **D. Quality:** T32 code review (5 axes) → security → performance → simplification → fixes. ✔ checkpoint.
- **E. Docs & ship (R9):** T33 docs + ADRs → T34 tag v1.1.0, release, verify artifacts.

## Risks
| Risk | Impact | Mitigation |
|---|---|---|
| GitHub macOS runner lacks Xcode 27 / macOS 27 SDK | High | Select newest Xcode on runner; deployment target macOS 15; fall back to `macos-latest` image Xcode |
| No Apple Developer ID on this machine | Med | Pipeline signs only when secrets present; unsigned DMG labeled + README Gatekeeper steps |
| OpenAI-compat servers differ in tool-call support | Med | Parse standard `tool_calls`; inline-JSON fallback already in Agent |

# v1.2 — Polish pass (2026-09-27)

## Overview
Fresh-eyes pass over v1.1: find and fix bugs and security issues, tighten the
model-switch UX, add a Homebrew cask download channel, cut v1.2.0 through the
existing CI/CD.

## Architecture decisions
- **No Mac App Store.** ADR-0001 stands: sandbox forbids synthetic paste, event
  taps, AppleScript to arbitrary apps, and spawning MCP servers. Downloads =
  notarized DMG on GitHub Releases + Homebrew cask (new).
- **CI/CD stays GitHub Actions** (remote is github.com; ADR-0004).
- Reviews run in fresh-context subagents; findings fixed test-first.

## Tasks
- T35 Independent 5-axis code review of full codebase → findings list.
  Accept: every Critical/High has a failing test, then a fix.
- T36 Security audit (agent tools, MCP, NetGuard, Keychain, file policy).
  Accept: new abuse cases in SecurityTests for each confirmed issue.
- T37 Model-switch UX check: menu bar + agent panel pickers reflect
  provider/installed models; empty/unreachable runtime shows actionable state.
  Accept: snapshot + unit tests where logic exists.
- T38 Homebrew cask: `scripts/cask.sh` renders `Casks/paluku.rb` from release
  version + sha256; release workflow attaches it. Accept: `brew style`/audit-able
  file; README install line.
- T39 Simplification pass on changed code; perf spot-check (PerfTests green).
- T40 Docs: README (run/dev/install/model switch), RELEASING (cask),
  CHANGELOG 1.2.0, ADR updates.
- T41 Ship: `scripts/release.sh 1.2.0` → CI green → Release has DMG, sha256,
  cask. Verify download checksum.

## Checkpoints
- After T35–T37: lint + test + Debug build green.
- After T38–T40: release script dry-run locally.
- After T41: GitHub Release verified.

## Risks
| Risk | Impact | Mitigation |
|---|---|---|
| No Developer ID secrets | Med | Unsigned DMG labeled; cask notes quarantine step |
| Review churn on security boundary | Med | Doubt-driven cycle on each security fix |
