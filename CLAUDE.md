# Paluku — agent notes

- Native macOS menu-bar app. Logic lives in `Packages/PalukuCore` (SwiftPM, Swift 5 language mode); the UI shell lives in `App/`. `Paluku.xcodeproj` is generated by XcodeGen from `project.yml` and is not committed.
- Gates: `scripts/lint.sh`, `scripts/test.sh`, `scripts/build.sh Debug`. Live suites need `PALUKU_LIVE=1` plus local Ollama/Whisper.
- The agent confirmation/taint policy lives only in `Agent.needsConfirmation`. When adding a tool, set its flags, and add an abuse-case test in `SecurityTests.swift` for anything touching files, network, AppleScript, shell or SQL.
- Tools run on the `Agent` actor, not the main thread. Use `await MainActor.run`, never `MainActor.assumeIsolated`, in tool hooks.
- `OllamaClient` sends `think: false` on purpose (it saves ~4 s per request, see docs/benchmark.md).
- Stored JSON types must decode older files: use `decodeIfPresent` with defaults for new fields.
- Specs: `SPEC.md`. Plan: `tasks/`. Decisions: `docs/decisions/`. Release process: `docs/RELEASING.md`.
